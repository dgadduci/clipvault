# Install ClipVault / Instalar ClipVault

Choose a language:

- [English](en.md)
- [Español](es.md)

The guides use the latest public [ClipVault release](https://github.com/dgadduci/clipvault/releases/latest). They were prepared against release `v0.0.20` on 2026-10-08. Check the release page for the current version and file names before downloading. On macOS, the official [Homebrew tap](https://github.com/dgadduci/homebrew-tap) installs the matching official DMG with a reviewed SHA-256; Homebrew requires `brew trust --cask dgadduci/tap/clipvault` before loading this external cask, and it preserves Gatekeeper checks. Release `v0.0.20` now includes an x86_64 RPM for direct installation. Fedora 44 package installation/removal and an openSUSE library check were run in containers; desktop launch and user-data preservation were not checked, so distribution compatibility is not claimed. The RPM is not yet in the signed Tauri updater manifest.
