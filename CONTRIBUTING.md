# Contributing to ClipVault / Contribuir a ClipVault

[English](#english) · [Español](#español)

## English

Thanks for your interest in ClipVault. Bug reports, documentation fixes and
focused code changes are welcome.

### Before opening a change

- For a reproducible bug or feature idea, use the corresponding GitHub issue
  form first.
- Keep changes focused and follow the repository architecture and privacy
  requirements in [AGENTS.md](AGENTS.md).
- Check [docs/development.md](docs/development.md) for the pinned toolchains
  and the relevant checks for the part of the app you changed. Do not include
  clipboard contents, secrets or personal data in issues, screenshots or logs.
- Describe what changed and what you verified. Manual checks are useful for
  desktop behavior that CI cannot reproduce, such as hotkeys, tray menus and
  Linux X11/Wayland sessions.

## Español

Gracias por tu interés en ClipVault. Son bienvenidos los reportes reproducibles,
las mejoras de documentación y los cambios de código acotados.

### Antes de proponer un cambio

- Para informar un error reproducible o proponer una función, usa primero el
  formulario correspondiente de GitHub Issues.
- Mantén los cambios acotados y sigue las reglas de arquitectura y privacidad
  de [AGENTS.md](AGENTS.md).
- Consulta [docs/development.md](docs/development.md) para conocer las versiones
  fijadas de las herramientas y las verificaciones relevantes para la parte que
  modificaste. No incluyas contenido del portapapeles, secretos ni datos
  personales en reportes, capturas o logs.
- Explica qué cambiaste y qué verificaste. Las pruebas manuales sirven para
  comportamientos que CI no puede reproducir, como atajos globales, menús de la
  barra y sesiones Linux X11/Wayland.

trabajo que tengas derecho a aportar.
