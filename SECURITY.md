# Security policy / Política de seguridad

[English](#english) · [Español](#español)

## English

Please do not report a suspected vulnerability in a public issue, discussion,
pull request or screenshot. Do not include clipboard contents, credentials,
tokens, private keys or personal data.

As of 2026-10-07, GitHub Private Vulnerability Reporting is not enabled for
this repository, and no private security contact is published here. Do not
send vulnerability details through public issues. The maintainer must enable
GitHub's private reporting feature or publish a private contact route before
reports with technical details can be accepted.

## Español

No informes una posible vulnerabilidad en un issue, discusión, pull request o
captura pública. No incluyas contenido del portapapeles, credenciales, tokens,
claves privadas ni datos personales.

Al 2026-10-07, GitHub Private Vulnerability Reporting no está habilitado para
este repositorio y aquí no se publica un contacto privado de seguridad. No
envíes detalles de vulnerabilidades mediante issues públicos. El mantenedor
debe habilitar la función de reportes privados de GitHub o publicar un medio
de contacto privado antes de aceptar reportes con detalles técnicos.
