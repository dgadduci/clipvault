# kde-wayland-source-app-detection

Cambio para identificar la aplicación activa en capturas nativas de KDE
Plasma Wayland y reutilizar el enriquecimiento local existente de nombre e
icono. macOS, GNOME X11 y GNOME Wayland conservan su comportamiento.

Estado: aprobado por instrucción del usuario el 2026-09-28; corrección de
implementación aplicada. La verificación manual en varias aplicaciones KDE
sigue pendiente.
