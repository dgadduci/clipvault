# kde-wayland-source-app-detection

Propuesta para identificar la aplicación activa en capturas nativas de KDE
Plasma Wayland y reutilizar el enriquecimiento local existente de nombre e
icono. macOS, GNOME X11 y GNOME Wayland deben conservar su comportamiento.

Estado: propuesta OpenSpec. No incluye cambios de implementación.
