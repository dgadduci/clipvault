# quick-paste-preview-ui

Tercera etapa de la evolución visual y funcional de Quick Paste. Este cambio
parte de `quick-paste-compact-ui` y `quick-paste-actions`, que ya establecieron
la ventana fija, la lista compacta, los favoritos, el menú y el flujo
copy-only de teclado.

Corrige los iconos ausentes, restaura el menú de acciones, agrega una
previsualización segura, incorpora `Cmd/Ctrl+K` para la búsqueda y alinea la
tipografía y los bordes con las cards del desktop principal.

Estado: preparado para implementación; MiniMax debe ejecutar únicamente las
tareas pendientes y no sincronizar ni archivar automáticamente.
