# desktop-dnd-card-visual-corrections

Cambio OpenSpec para corregir la asignación real de cards por drag-and-drop,
mostrar feedback visual suave en las colecciones y completar ajustes visuales
de las cards y del desktop.

El icono de favorito se rediseña como una chincheta o pushpin minimalista,
nunca como una estrella.

Estado: implementación activa; el flujo requiere verificación manual en
macOS/Tauri antes de archivar.

No archivar este cambio al finalizar sin una instrucción explícita.
