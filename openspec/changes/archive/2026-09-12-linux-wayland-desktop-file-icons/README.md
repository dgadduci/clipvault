# linux-wayland-desktop-file-icons

Cambio propuesto para resolver metadata e iconos locales cuando GNOME Wayland
entrega un Desktop File ID válido, sin ampliar el canal metadata-only de la
extensión ni convertir identificadores `window:*` en una identidad inventada.

Estado: cerrado por decisión explícita. Las tareas manuales pendientes se
aceptan como cierre documental para este cambio; la selección visual de
blacklist en Linux se difiere a `linux-blacklist-app-picker`.
