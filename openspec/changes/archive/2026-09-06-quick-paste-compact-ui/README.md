# quick-paste-compact-ui

Primera etapa de la evolución de Quick Paste. Reutiliza la ventana transient,
el hotkey, la búsqueda, la selección y el flujo de pegado existentes, y
establece una superficie compacta de tamaño fijo para el uso cotidiano.

Este cambio debe implementarse antes de `quick-paste-actions`, que agregará
favoritos, menú de pegado y modalidades de teclado sobre este layout estable.

Estado: preparado para implementación; no archivar automáticamente.
