# source-app-filter

Este cambio agrega un filtro de aplicación fuente al desktop de ClipVault. El
combobox se ubica entre la búsqueda y el menú de configuración, incluye
`Todas` como primera opción y muestra icono y nombre de cada aplicación
presente en el alcance activo.

El filtro se combina con la colección activa y con la búsqueda de texto. La
consulta se ejecuta al seleccionar una opción, sin botón Aplicar.

Estado: propuesto, pendiente de implementación.

No archivar ni sincronizar este cambio hasta completar la implementación y la
verificación manual. La verificación manual pendiente de
`platform-permission-guidance` es independiente y no debe modificarse.
