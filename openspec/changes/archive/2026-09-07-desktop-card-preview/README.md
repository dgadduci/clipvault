# desktop-card-preview

Extiende las cards del Desktop con la previsualización que ya existe en Quick
Paste.

La preview debe compartir componente, helpers, sanitización, resolver de
assets, estados de carga y ciclo de vida entre ambas superficies. El atajo es
`Cmd+Enter` en macOS y `Ctrl+Enter` en Linux; el menú de cada card agrega
`Previsualizar`.

Estado: propuesta preparada para implementación por MiniMax. No implementado,
no sincronizado y no archivado.
