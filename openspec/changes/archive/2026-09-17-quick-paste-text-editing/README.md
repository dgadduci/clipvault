# quick-paste-text-editing

Extensión de Quick Paste para editar capturas de texto desde el menú de cada
resultado y conservar los cambios en la misma entrada persistida.

El cambio reutiliza el comando, las validaciones, el modal y los atajos que ya
existen en el desktop principal. También muestra los atajos de edición y
previsualización junto a sus acciones correspondientes del menú.

Estado: implementación verificada automáticamente y aprobada manualmente en
Linux y macOS. El cambio está completo y listo para sincronizar y archivar.

La implementación y las verificaciones requeridas están completas. La
sincronización y el archivado se realizan manualmente.
