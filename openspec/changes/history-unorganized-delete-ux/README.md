# history-unorganized-delete-ux

Este cambio aclara la acción de borrado general del desktop. El basurero sólo
se muestra cuando la vista activa es `Historial` y su tooltip, nombre accesible
y confirmación explican que elimina capturas no favoritas y sin colecciones de
usuario.

La acción `Quitar de esta colección` continúa siendo la operación contextual
para una card dentro de una colección. El borrado individual del menú de una
card también conserva su contrato actual.

Estado: propuesto, pendiente de implementación.

No archivar ni sincronizar este cambio hasta completar la implementación y la
verificación manual.
