# Propuesta: crear la página de entrada pública de ClipVault

## Problema

El repositorio no tiene un README en la raíz ni metadata orientada a que una
persona pueda encontrar y evaluar la aplicación en GitHub. Las guías y
archivos de confianza se implementan en cambios separados; esta pieza debe
presentarlos como un recorrido claro en lugar de repetir instrucciones.

## Qué cambia

- Crear un README de raíz en inglés con versión equivalente en español.
- Explicar ClipVault en una frase y mostrar capturas actuales aprobadas por el
  usuario para publicación,
  enlazar los releases y dirigir a las guías de instalación, privacidad,
  soporte y contribución.
- Enumerar solo capacidades presentes en la versión pública enlazada.
- Preparar la descripción, topics y website recomendados para GitHub About.
- Crear una imagen social de GitHub con el logo actual y texto breve.

## Fuera de alcance

- Publicar una release, cambiar settings del repositorio remoto o modificar la
  página de GitHub desde una API.
- Afirmar soporte para Windows, paquetes no publicados o funciones del roadmap.
- Exponer credenciales o secretos, o publicar capturas sin aprobación explícita
  del usuario para uso público.
- Hacer afirmaciones absolutas como “sin conexiones a Internet”; el actualizador
  consulta GitHub y eso debe describirse de forma precisa.

## Resultado esperado

Una persona que abre el repositorio entiende qué problema resuelve ClipVault,
puede ver la aplicación real y encuentra en uno o dos saltos el release y la
guía correcta en inglés o español.
