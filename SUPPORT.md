# ClipVault support / Ayuda de ClipVault

[English](#english) · [Español](#español)

## English

- Download the latest official installers from [GitHub Releases](https://github.com/dgadduci/clipvault/releases).
- For installation and update details, see [release documentation](docs/releases.md).
- To report a reproducible problem or request a feature, [open a GitHub issue](https://github.com/dgadduci/clipvault/issues/new/choose).
- Include the ClipVault version and relevant operating system, desktop and
  X11/Wayland session details. State what you expected and what happened.
- Do not attach clipboard history, screenshots containing private entries,
  credentials, tokens, database files or unredacted logs.

Support is provided through the public repository. No response time is
guaranteed. For security issues, follow [SECURITY.md](SECURITY.md) instead of
opening a public issue.

## Español

- Descarga los instaladores oficiales más recientes desde [GitHub Releases](https://github.com/dgadduci/clipvault/releases).
- Para detalles sobre instalación y actualizaciones, consulta la
  [documentación de releases](docs/releases.md).
- Para reportar un problema reproducible o proponer una función,
  [crea un issue en GitHub](https://github.com/dgadduci/clipvault/issues/new/choose).
- Incluye la versión de ClipVault y los datos pertinentes del sistema
  operativo, escritorio y sesión X11/Wayland. Explica qué esperabas y qué
  ocurrió.
- No adjuntes historial del portapapeles, capturas con entradas privadas,
  credenciales, tokens, archivos de base de datos ni logs sin revisar.

La ayuda se ofrece a través del repositorio público; no se garantiza un plazo
de respuesta. Para problemas de seguridad, sigue [SECURITY.md](SECURITY.md) en
lugar de abrir un issue público.
